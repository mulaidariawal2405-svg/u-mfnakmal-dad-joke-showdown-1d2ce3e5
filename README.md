# Dad Joke Showdown

One dad joke, at most 200 characters, written to `/output/entry.txt`.

The joke: "I told my kids I was going to grill them at the barbecue. They said, Dad, we're already well done."

Run it with plain Python 3, no dependencies:

```
python3 main.py
```

It checks the joke is a single line of 1-200 characters, writes it to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set), and prints it.
